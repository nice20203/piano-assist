弹琴辅助 Piano Assist  v1.0.0
================================

【运行】
1. 右键 PianoAssist.exe  ->  以管理员身份运行
   （游戏是管理员权限启动的，权限不对可能收不到你的按键）

2. 游戏改成【窗口化】或【无边框窗口】，打开乐器界面
   注意：不要用全屏独占，覆盖层会被挡住

3. 按 F7 -> 拖动屏幕上的提示条，对齐到游戏里的琴键 -> 再按 F7 保存

4. 把简谱粘进输入框 -> 点「解析」-> 按 F8 开始

【热键】
  F5   显示 / 隐藏提示条
  F6   改键模式（点琴键 -> 按新键）
  F7   标定模式（拖动 / 缩放对齐）
  F8   开始 / 停止
  F9   重来

【常见问题】
Q: 打开时提示"Windows 已保护你的电脑"
A: 点「更多信息」->「仍要运行」。程序没有代码签名，属正常提示。

Q: 杀毒软件报警 / 文件被删
A: 这是 PyInstaller 打包的程序 + 全局键盘钩子，容易被误报。
   介意的话请改用源码版运行（见 GitHub 上的 source 包）。

Q: 按了 F8 但游戏没反应
A: 确认是本程序用【管理员身份】运行的；确认热键没被别的软件占用。

Q: 覆盖层看不到
A: 按 F5 切换显示；或用主窗口第⑤区的数值微调把它拉回屏幕内。
