# 弹琴辅助 · Piano Assist

简体中文 · [English](README.en.md)

> **一款"不替你弹"的弹琴练习辅助工具 —— 它只告诉你该按哪个键，弹还是你自己弹。**

把简谱粘进来，屏幕上就会出现一条半透明的键位提示条：**该按哪个键，哪个键就亮**。
按对了往下一个走，按错了可以卡住不放、也可以闪红继续。

通过**键位预设**可以适配不同游戏里有乐器玩法的场景。目前内置了 **第五人格（Identity V）**
的完整版 36 键 / 基础版 21 键两套预设，并在 PC 端实测可用。

## ✨ 核心特点

### 🚫 不模拟按键，只做提示

这是本工具和"自动弹琴"最本质的区别：

| | 自动弹琴类工具 | **本工具** |
|---|---|---|
| 模拟按键 | ✅ 代替你弹 | ❌ **完全不模拟** |
| 读取键盘 | — | ✅ 全局钩子（只读） |
| 你的角色 | 看着它弹 | **你自己弹** |
| 提升了什么 | 结果 | **你的手感** |

**你不按，它什么都不会发生。** 它只是把你眼睛和手之间的"换算"这一步省掉了 ——
简谱写的是 `1 2 3`，你得在脑子里转成音高、再去找键位；而它直接把 `A S D` 亮给你。

### 🎯 双模式：先熟悉，再练时机

```
【顺序模式】—— 等你
   ├─ 按错：卡住不放    ← 学得最牢
   └─ 按错：闪红继续    ← 流畅通顺
【时间模式】—— 不等你，统一节拍，可调速
```

- **顺序模式**（核心）：你按对了才往下走，用来**熟悉曲子**
- **时间模式**（进阶）：到点就亮、不等你，用来在有基础之后**练节奏和时机**

### 🎹 可标定的透明覆盖层

- 半透明、鼠标穿透、始终置顶，不挡操作
- **跟随游戏窗口**：存的是相对坐标，窗口移动 / 换分辨率都不会错位
- **可视化标定**：按一下热键即可拖动缩放，对齐到游戏里的琴键上
- 找不到感觉还能用**数值微调面板**，精确到像素

### 🔧 键位可改，预设可加

- **点一下就能改键**：进改键模式 → 点覆盖层上的琴键 → 按新键，立即生效
- 冲突时**自动交换**，保证一键一音
- 键位方案存在 `presets/*.json`，**加一套新键位 = 加一个 JSON 文件**，不用改代码

### 📚 曲库与连弹

- 琴谱可保存进曲库、一键载入
- **自动识别曲名**（从谱面的 `# 歌名` 注释行读）
- 勾上「弹完自动下一首」，一首接一首连着练

## 🚀 快速开始

### 环境

- Windows 10 / 11
- Python 3.10+（或 [uv](https://github.com/astral-sh/uv)）

### 运行

```bash
# 方式一：直接用 python
pip install pynput
python main.py

# 方式二：用 uv（会自动装依赖）
uv run python main.py
```

Windows 用户也可以直接双击 **`启动.bat`**（会自动请求管理员权限、自动找 Python 环境、出错时暂停显示错误）。

> ⚠️ **建议以管理员身份运行**：部分游戏以管理员权限启动，权限不对可能收不到你的按键。

### 三步用起来

```
1. 游戏改成【窗口化】或【无边框窗口】，打开乐器界面
2. 运行本工具 → 按 F7 拖动覆盖层，对齐到游戏里的琴键 → 再按 F7 保存
3. 把简谱粘进输入框 → 点「解析」→ 按 F8 开始
```

> **不要用全屏独占** —— 那是系统层面的独占，任何覆盖层都盖不上去。

## ⌨️ 热键

| 键 | 功能 |
|---|---|
| `F5` | 显示 / 隐藏覆盖层（不想被挡时按一下，不用关软件） |
| `F6` | 改键模式（点琴键 → 按新键） |
| `F7` | 标定模式（拖动 / 缩放覆盖层对齐） |
| `F8` | 开始 / 停止 |
| `F9` | 重来 |

热键是**全局**的，游戏在前台也有效。

## 🎼 琴谱从哪来

### 谱面格式

工具吃的是**简谱文本**，一行一个「时刻」：

```
# 起风了        ← 行首 # 是曲名，保存时会自动带上
5
6
1'
|
5 1'           ← 同一行 = 同时按（和弦）
3
```

| 记号 | 含义 |
|---|---|
| `1`-`7` | 音高 |
| `1'` / `1''` | 高一个 / 两个八度 |
| `1,` / `1,,` | 低一个 / 两个八度 |
| `3#` / `7b` | 升 / 降 |
| 行内空格 | 同时按（和弦） |
| `\|` 单独一行 | 小节线 |

### 用 AI 从图片扒谱

抖音 / B 站上的琴谱大多是图片，可以用视觉大模型（豆包等）转成上述文本。
**让 AI 输出固定格式**是成功率的关键，提示词模板见 👉 [`docs/豆包提示词.md`](docs/豆包提示词.md)

## 🎮 适配其他游戏

本工具的核心是通用的：**简谱解析 + 双模式引擎 + 可标定覆盖层提示**，
跟具体是哪个游戏无关。游戏差异只在"键位怎么映射"。

要适配一个新游戏：

1. 在 `presets/` 里加一个 JSON，写明这个游戏乐器的键位映射
2. 重启工具，在「键位」区选择新方案
3. 用 F7 把覆盖层对齐到该游戏的乐器界面

```json
{
  "id": "your-game-instrument",
  "name": "某游戏 · 乐器名",
  "game": "某游戏",
  "default": false,
  "cols": 12,
  "description": "说明这个布局",
  "map": { "60": "Z", "62": "X" }
}
```

- `map` 的键是 MIDI 音高（C4 = 60），值是要按的键盘按键
- `cols` 是覆盖层每行画几列

## 🗂 文件结构

```
PianoAssist/
├── main.py              主程序：界面、热键、事件分发、曲库
├── overlay.py           覆盖层：透明/穿透/置顶、标定、改键、拖动
├── engine.py            双模式引擎：顺序(卡住/闪红) + 时间(统一节拍)
├── score.py             简谱解析：和弦、小节线、八度点、升降、折叠
├── keys.py              键位预设管理：加载/切换/改键/持久化
├── library.py           曲库：保存、载入、曲名识别、连弹
├── presets/             键位预设（一个 JSON = 一套键位方案）
├── docs/                文档
└── 启动.bat             Windows 启动器
```

**运行时会生成**（已在 `.gitignore` 中排除）：

| 文件 | 内容 |
|---|---|
| `keymap.json` | 各预设下你自己改过的键位 |
| `calib.json` | 覆盖层的标定位置 |
| `曲库/` | 你保存的琴谱 |
