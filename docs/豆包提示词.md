# 用 AI 把琴谱图片转成可用文本

抖音 / B 站上的琴谱大多是图片。用带视觉能力的 AI（豆包、通义千问-VL、GPT-4o 等）
就能转成本工具能吃的简谱文本。

**关键：必须让 AI 输出固定格式**，否则解析器吃不下，或者格式乱七八糟。

---

## 通用提示词（推荐直接用这个）

把下面整段发给 AI，再附上琴谱图片：

```
你把这张简谱图片转成纯文本。严格按下面的规则输出，不要有任何多余的话。

【输出格式】
第 1 行：井号 + 空格 + 歌名，例如：  # 起风了
之后每一行：一个"时刻"

【音符规则】
- 音高用简谱数字 1-7 写（1 就是这首歌的主音），这样天然不会有升降号
- 高八度 → 数字后加 '        低八度 → 数字后加 ,
- 同一行写多个音（空格隔开）= 同时按（和弦）
  ★ 谱面上上下叠放、或并排在同一拍的音，必须写在【同一行】，不要拆成两行
- 每 4 拍插入一条小节线：单独占一行写作 |
- 升号 # / 降号 b 写在数字后面（如 3#、7b）

【歌名怎么定】
- 图片上有标题 → 直接用那个标题
- 没有标题但能认出是什么歌 → 写出正确的歌名
- 实在认不出 → 就写  # 未知曲目

【禁止】
- 不要开场白、不要序号、不要解释、不要总结
- 不要用 markdown 代码块包起来
- 不要自己编和弦（谱子上没有和弦就保持单音）

【正确示例】
# 起风了
5
6
1'
|
5 1'
3
2

只输出谱子内容。
```

---

## 加上「音域约束」（推荐）

不同游戏乐器的音域是有限的。提前告诉 AI 这个限制，能**大幅减少后期调整**。

在提示词里插入这一段（以第五人格为例）：

```
【乐器音域 —— 必须遵守】
这个乐器只有 3 个八度，音域从低音 do 到高音 si。
用简谱写就是下面这些音：

  低八度（数字后加逗号）：1, 2, 3, 4, 5, 6, 7,
  中八度（不加记号）：    1  2  3  4  5  6  7
  高八度（数字后加撇）：  1' 2' 3' 4' 5' 6' 7'

遇到这个范围以外的音：
  · 比 7' 还高 → 降一个八度写
  · 比 1, 还低 → 升一个八度写
  · 实在放不进去 → 跳过，不要瞎编
```

**如果乐器支持半音**（游戏里开启了黑键），再补一句：

```
另外还有 5 个半音：#1 #2 #4 #5 #6，同样分三个八度。
```

## 导入之后怎么检查

粘进工具、点「解析」，看这两处：

| 看哪里 | 说明 |
|---|---|
| **状态栏** | `N 个音 \| 音域 X~Y \| 折叠 N \| 黑键归位 N` |
| **预览区** | 简谱 ↔ 键位 逐行对照 |

- **`折叠 0`、`黑键归位 0`** = 完美命中，谱子完全落在乐器音域内
- **有折叠** = 有音超出了音域，工具自动按八度折回来了（可以用，但音会变）
- **有黑键归位** = 谱子里有 `#`/`b`，但当前键位预设弹不了，被就近归到白键了

## 常见问题

**Q：AI 老是加解释、加序号怎么办？**

在提示词最后补一句：

```
如果你多写了任何一个字，我就得手动删掉，请严格遵守格式。
```

**Q：AI 漏了歌名？**

不影响，保存时工具会弹框让你手输。

**Q：识别出来的音不对？**

- 先核对是不是**音区**认错了（上点 / 下点最容易漏）—— 对照原图检查
- 图片太糊、手写体、带装饰音，识别率都会下降
- 实在不行就手动改：直接在输入框里改文本，或者用 F6 改键

**Q：和弦没识别出来？**

和弦要求 AI「把上下叠放 / 同拍的音写在**同一行**」。
不过很多简谱本身就只有单音旋律 —— 那就保持单音，别让 AI 编。
